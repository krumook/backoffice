📚 0580 Paper Breakdown — Core Papers

Personal question bank for IGCSE 0580 (Cambridge) Core past papers — Paper 1 (non-calculator) and Paper 3 (calculator), for students sitting the Core tier. Kept as a completely separate dashboard from the Extended breakdowns (current syllabus and pre-2025) — no shared papers, counts, or totals.

A note on topic codes: questions here use the same 9 main topics as the Extended dashboards, with Core sub-codes (C1.1, C2.5, etc.) numbered to match the current 2025–2027 syllabus. Core and Extended share most topic numbering, so these are practical labels for organising questions rather than an exact copy of the syllabus wording. Marks shown for a topic are the marks for just the matching part of a question, so a multi-part question can appear under more than one topic.
