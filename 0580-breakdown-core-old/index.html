📚 0580 Paper Breakdown — Core Papers (Pre-2025)

Personal question bank for older IGCSE 0580 (Cambridge) Core past papers — anything from before the current 2025–2027 syllabus cycle. Before 2025, Core Paper 1 was a 56-mark calculator paper and Core Paper 3 was a 104-mark structured paper, so these are kept apart from the current-syllabus Core dashboard and from the pre-2025 Extended dashboard — no shared papers, counts, or totals.

A note on topic codes: there is no separate old-syllabus reference on hand, so questions here use the same 9 main topics and Core sub-codes (C1.1, C2.5, etc.) as the current Core dashboard, as a practical stand-in. Exact sub-code numbering for a pre-2025 paper may not match what was examinable when it was sat. Marks shown for a topic are the marks for just the matching part of a question, so a multi-part question can appear under more than one topic.
