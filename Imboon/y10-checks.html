Unit 1Algebraic Manipulation6 subtopics

1.1Expanding double brackets

Key learning: Multiply every term in the first bracket by every term in the second, then collect like terms. Watch the signs.

Check: Expand and simplify (x + 3)(x − 6).
Show answer
x² − 3x − 18
Stretch: Expand and simplify (2x − 5)(3x + 4).
Show answer
6x² − 7x − 20

1.2Factorising x² + bx + c

Key learning: Find two numbers that multiply to give c and add to give b, then write them in two brackets.

Check: Factorise x² − 6x − 16.
Show answer
(x − 8)(x + 2)
Stretch: Factorise x² + 11x + 28.
Show answer
(x + 4)(x + 7)

1.3Expanding triple brackets

Key learning: Expand two brackets first, then multiply the result by the third bracket, taking care to multiply every term.

Check: Expand and simplify (x + 2)(x − 3)(x + 5).
Show answer
x³ + 4x² − 11x − 30
Stretch: Expand and simplify (x − 1)(x + 2)(x + 4).
Show answer
x³ + 5x² + 2x − 8

1.4Difference of two squares

Key learning: a² − b² = (a − b)(a + b). Spot it when there are two perfect squares separated by a minus sign.

Check: Factorise x² − 49.
Show answer
(x − 7)(x + 7)
Stretch: Factorise 9x² − 25y².
Show answer
(3x − 5y)(3x + 5y)

1.5Factorising ax² + bx + c (a > 1)

Key learning: Multiply a × c, find two numbers with that product that add to b, split the middle term, then factorise in pairs.

Check: Factorise 2x² − x − 21.
Show answer
(2x − 7)(x + 3)
Stretch: Factorise 6x² + 13x − 5.
Show answer
(3x − 1)(2x + 5)

1.6Quadratic expressions in area problems

Key learning: Write each side as an expression, multiply for area, set up the equation, then expand, rearrange and solve. Reject any negative length.

Check: A rectangle has sides (x + 3) cm and (x − 1) cm. Its area is 21 cm². Find x.
Show answer
(x + 3)(x − 1) = 21 → x² + 2x − 24 = 0 → (x + 6)(x − 4) = 0. x = 4 (x = −6 is impossible). Sides 7 cm and 3 cm.
Stretch: A square of side (x + 2) cm has the same area as a rectangle (x + 8) cm by (x − 1) cm. Find x.
Show answer
x² + 4x + 4 = x² + 7x − 8 → 12 = 3x → x = 4. (Both areas = 36 cm².)
Unit 2Solving Quadratics7 subtopics

2.1Solving by factorising (a = 1)

Key learning: Rearrange to equal 0, factorise, then set each bracket equal to 0.

Check: Solve x² + x − 30 = 0.
Show answer
(x + 6)(x − 5) = 0, so x = −6 or x = 5
Stretch: Solve x² − 3x = 28.
Show answer
x² − 3x − 28 = 0 → (x − 7)(x + 4) = 0, so x = 7 or x = −4

2.2The quadratic formula

Key learning: x = (−b ± √(b² − 4ac)) / 2a. Substitute carefully, using brackets for negative values. Give decimals to 3 s.f. unless told otherwise.

Check: Solve x² + 3x − 5 = 0, giving answers to 3 s.f.
Show answer
x = (−3 ± √29)/2, so x = 1.19 or x = −4.19
Stretch: Solve 3x² − 4x − 2 = 0, giving answers to 3 s.f.
Show answer
x = (4 ± √40)/6, so x = 1.72 or x = −0.387

2.3Factorising when a > 1

Key learning: Use the “a × c” method or trial and error. Put equations in the form ax² + bx + c = 0 first.

Check: Solve 2x² − 3x + 1 = 0.
Show answer
(2x − 1)(x − 1) = 0, so x = ½ or x = 1
Stretch: Solve x(3x − 2) = 5.
Show answer
3x² − 2x − 5 = 0 → (3x − 5)(x + 1) = 0, so x = 5/3 or x = −1

2.4Non-linear simultaneous equations

Key learning: Substitute the linear equation into the non-linear one, solve the quadratic, then find each y value. There are usually two pairs of answers.

Check: Solve y = x − 4 and x² + y² = 40.
Show answer
x² + (x − 4)² = 40 → x² − 4x − 12 = 0 → (x − 6)(x + 2) = 0. (x, y) = (6, 2) and (−2, −6).
Stretch: Solve y = 11x − 2 and y = 5x².
Show answer
5x² − 11x + 2 = 0 → (5x − 1)(x − 2) = 0. (x, y) = (0.2, 0.2) and (2, 20).

2.5Completing the square (a = 1)

Key learning: x² + bx + c = (x + b/2)² + c − (b/2)². Then rearrange to solve, remembering ±.

Check: Write x² + 8x + 2 in the form (x + p)² + q, then solve x² + 8x + 2 = 0 (2 d.p.).
Show answer
(x + 4)² − 14. x = −4 ± √14, so x = −0.26 or x = −7.74
Stretch: Solve x² − 5x + 1 = 0 by completing the square (2 d.p.).
Show answer
(x − 2.5)² − 5.25 = 0, so x = 2.5 ± √5.25 = 4.79 or 0.21

2.6Forming and solving from context

Key learning: Define the unknown, write an expression for each quantity, form the equation, solve, then check the answer makes sense in the question.

Check: A rectangle is 3 cm longer than it is wide. Its area is 54 cm². Find its width.
Show answer
x(x + 3) = 54 → x² + 3x − 54 = 0 → (x + 9)(x − 6) = 0. Width = 6 cm (length 9 cm).
Stretch: Solve 3/(x + 5) + 6/(2x + 1) = 1.
Show answer
3(2x + 1) + 6(x + 5) = (x + 5)(2x + 1) → 2x² − x − 28 = 0 → (2x + 7)(x − 4) = 0. x = 4 or x = −3.5

2.7Completing the square when a > 1

Key learning: Factor out a from the x² and x terms first, complete the square inside the bracket, then multiply out the constant.

Check: Write 2x² − 12x + 7 in the form a(x + p)² + q.
Show answer
2(x − 3)² − 11
Stretch: Use your answer to solve 2x² − 12x + 7 = 0 (3 s.f.).
Show answer
(x − 3)² = 5.5, so x = 3 ± √5.5 = 5.35 or 0.655
Unit 3Percentages7 subtopics

3.1Percentage of an amount

Key learning: Convert the percentage to a decimal multiplier (35% = 0.35) and multiply.

Check: Find 35% of $240.
Show answer
0.35 × 240 = $84
Stretch: Find 12.5% of 360.
Show answer
0.125 × 360 = 45

3.2Increase and decrease with multipliers

Key learning: Increase by r%: multiply by 1 + r/100. Decrease by r%: multiply by 1 − r/100.

Check: Increase 120 by 12%.
Show answer
120 × 1.12 = 134.4
Stretch: Decrease £250 by 18%.
Show answer
250 × 0.82 = £205

3.3Compound interest and depreciation

Key learning: Multiplier raised to the power of the number of years: amount × (multiplier)n.

Check: $5000 is invested at 3% compound interest per year. Find the value after 4 years.
Show answer
5000 × 1.034 = $5627.54
Stretch: A car worth £12 000 depreciates by 15% each year. Find its value after 3 years.
Show answer
12 000 × 0.853 = £7369.50

3.4Percentage change problems

Key learning: Percentage change = (change ÷ original) × 100. Always divide by the original value.

Check: A price rises from $80 to $92. Find the percentage increase.
Show answer
12/80 × 100 = 15%
Stretch: A laptop is reduced from $650 to $533. Find the percentage reduction.
Show answer
117/650 × 100 = 18%

3.5Reverse percentages

Key learning: The new value is a percentage of the original, so divide by the multiplier to get back to the original.

Check: After a 20% increase a price is $96. Find the original price.
Show answer
96 ÷ 1.20 = $80
Stretch: A coat is sold for £357 after a 15% discount. Find the original price.
Show answer
357 ÷ 0.85 = £420

3.6Repeated percentage change

Key learning: Multiply the multipliers together. A rise of 20% then a fall of 20% is not back to the start.

Check: A population of 25 000 grows by 8% per year. Find the population after 3 years (nearest whole number).
Show answer
25 000 × 1.083 = 31 493
Stretch: A price increases by 20%, then decreases by 20%. What is the overall percentage change?
Show answer
1.2 × 0.8 = 0.96, so a 4% decrease

3.7Compound interest problems

Key learning: Use trial of whole years, or work out the rate from the final multiplier, by taking roots.

Check: How many whole years until $2000 invested at 4% compound interest exceeds $2500?
Show answer
1.04n > 1.25. 1.045 = 1.217, 1.046 = 1.265, so 6 years.
Stretch: $8000 grows to $9261 in 3 years of compound interest. Find the annual rate.
Show answer
9261/8000 = 1.157625 = 1.05<sup>3</sup>, so 5%
Unit 4Volume and Surface Area8 subtopics

4.1Properties of 3D shapes

Key learning: Faces are flat surfaces, edges are where faces meet, vertices are corners. Euler: V + F − E = 2.

Check: State the number of faces, edges and vertices of a triangular prism.
Show answer
5 faces, 9 edges, 6 vertices
Stretch: State the number of faces, edges and vertices of a square-based pyramid.
Show answer
5 faces, 8 edges, 5 vertices

4.2Volume of prisms and cuboids

Key learning: Volume of a prism = area of cross-section × length.

Check: Find the volume of a cuboid 8 cm by 5 cm by 3 cm.
Show answer
8 × 5 × 3 = 120 cm³
Stretch: A prism has a triangular cross-section with base 6 cm and height 4 cm. It is 10 cm long. Find its volume.
Show answer
½ × 6 × 4 = 12 cm²; 12 × 10 = 120 cm³

4.3Surface area of cuboids and prisms

Key learning: Add the areas of all the faces. Count every face: a cuboid has 6.

Check: Find the surface area of a cuboid 8 cm by 5 cm by 3 cm.
Show answer
2(8×5 + 8×3 + 5×3) = 2(40 + 24 + 15) = 158 cm²
Stretch: A prism has a right-angled triangle cross-section with sides 3 cm, 4 cm, 5 cm and is 10 cm long. Find its surface area.
Show answer
Two triangles 2 × 6 = 12; rectangles 30 + 40 + 50 = 120; total 132 cm²

4.4Cylinders

Key learning: V = πr²h. Curved surface area = 2πrh. Total surface area = 2πr² + 2πrh.

Check: A cylinder has radius 4 cm and height 10 cm. Find its volume and total surface area (3 s.f.).
Show answer
V = π × 16 × 10 = 503 cm³. SA = 32π + 80π = 112π = 352 cm²
Stretch: A cylinder has volume 500 cm³ and radius 5 cm. Find its height (3 s.f.).
Show answer
h = 500 ÷ (25π) = 6.37 cm

4.5Converting metric units

Key learning: Length ×10 per step for cm→mm, but area uses the factor squared and volume uses it cubed. 1 litre = 1000 cm³.

Check: Convert 2.5 m³ to cm³ and 4500 cm² to m².
Show answer
2.5 × 1 000 000 = 2 500 000 cm³. 4500 ÷ 10 000 = 0.45 m²
Stretch: A tank measures 40 cm by 25 cm by 30 cm. How many litres does it hold?
Show answer
30 000 cm³ = 30 litres

4.6Cones and spheres (formulae given)

Key learning: Cone: V = ⅓πr²h, curved SA = πrl. Sphere: V = ⅴπr³, SA = 4πr². Use Pythagoras to find l.

Check: A cone has radius 6 cm and height 8 cm. Find its volume and curved surface area (3 s.f.).
Show answer
V = ⅓π(36)(8) = 302 cm³. l = √(36 + 64) = 10, curved SA = π(6)(10) = 189 cm²
Stretch: Find the total surface area of a solid hemisphere of radius 5 cm (3 s.f.).
Show answer
Curved 2πr² = 50π plus flat πr² = 25π; total 75π = 236 cm²

4.7Similar shapes (areas and volumes)

Key learning: If lengths are in ratio 1 : k, areas are 1 : k² and volumes are 1 : k³.

Check: Two similar solids have lengths in the ratio 2 : 3. The smaller has volume 40 cm³. Find the volume of the larger.
Show answer
Volume ratio 8 : 27. 40 × 27/8 = 135 cm³
Stretch: Two similar bottles have surface areas 50 cm² and 200 cm². The larger holds 240 cm³. Find the volume of the smaller.
Show answer
Area ratio 1 : 4, so length ratio 1 : 2 and volume ratio 1 : 8. 240 ÷ 8 = 30 cm³

4.8Compound solids

Key learning: Split into simple solids, find each volume or area, then add. Do not count the joined faces in surface area.

Check: A solid is a hemisphere of radius 6 cm on top of a cylinder of radius 6 cm and height 10 cm. Find its volume (4 s.f.).
Show answer
Hemisphere ⅔π(216) = 144π; cylinder π(36)(10) = 360π; total 504π = 1583 cm³
Stretch: Find the volume of a square-based pyramid with base side 6 cm and height 4 cm.
Show answer
⅓ × 36 × 4 = 48 cm³
Unit 5Compound Measures9 subtopics

5.1Speed, distance and time

Key learning: speed = distance ÷ time. Use the triangle D / (S × T). Change minutes to hours before using km/h.

Check: A car travels 150 km in 2.5 hours. Find its average speed.
Show answer
150 ÷ 2.5 = 60 km/h
Stretch: A train travels at 72 km/h for 45 minutes. Find the distance.
Show answer
72 × 0.75 = 54 km

5.2Density

Key learning: density = mass ÷ volume.

Check: A metal block has mass 450 g and volume 50 cm³. Find its density.
Show answer
450 ÷ 50 = 9 g/cm³
Stretch: Aluminium has density 2.7 g/cm³. Find the volume of 2.7 kg of aluminium.
Show answer
2700 ÷ 2.7 = 1000 cm³

5.3Pressure

Key learning: pressure = force ÷ area (formula given in the exam).

Check: A force of 600 N acts on an area of 0.3 m². Find the pressure.
Show answer
600 ÷ 0.3 = 2000 N/m²
Stretch: A pressure of 50 N/m² is caused by a force of 1200 N. Find the area.
Show answer
1200 ÷ 50 = 24 m²

5.4Speed with unit conversions

Key learning: To change km/h to m/s, multiply by 1000 and divide by 3600 (divide by 3.6).

Check: Change 72 km/h into m/s.
Show answer
72 ÷ 3.6 = 20 m/s
Stretch: A runner covers 400 m in 50 s. Find the speed in km/h.
Show answer
8 m/s × 3.6 = 28.8 km/h

5.5Density with unit conversions

Key learning: Convert to the same units before dividing. 1 g/cm³ = 1000 kg/m³.

Check: 0.5 m³ of wood has mass 350 kg. Find its density in kg/m³ and in g/cm³.
Show answer
700 kg/m³ = 0.7 g/cm³
Stretch: A block 20 cm by 10 cm by 5 cm has mass 2.5 kg. Find the density in g/cm³.
Show answer
Volume 1000 cm³; 2500 ÷ 1000 = 2.5 g/cm³

5.6Pressure involving surface area

Key learning: Work out the area of the face in contact with the surface first, in the right units.

Check: A 90 N crate rests on a face 0.5 m by 0.3 m. Find the pressure.
Show answer
Area 0.15 m²; 90 ÷ 0.15 = 600 N/m²
Stretch: A cylinder of weight 400 N stands on a circular base of radius 0.1 m. Find the pressure (3 s.f.).
Show answer
Area π(0.1)² = 0.0314 m²; 400 ÷ 0.0314 = 12 700 N/m²

5.7Multiple journeys and average speed

Key learning: Average speed = total distance ÷ total time. Never average the speeds.

Check: Anna drives 80 km at 40 km/h then 120 km at 60 km/h. Find her average speed.
Show answer
Times 2 h and 2 h; 200 ÷ 4 = 50 km/h
Stretch: A cyclist rides out at 30 km/h and returns the same route at 60 km/h. Find the average speed.
Show answer
Let the distance be d: total 2d ÷ (d/30 + d/60) = 40 km/h (not 45)

5.8More than one density

Key learning: Find each volume separately, add them, and divide the total mass by the total volume.

Check: An alloy has 300 g of metal A (density 6 g/cm³) and 200 g of metal B (density 4 g/cm³). Find the density of the alloy.
Show answer
Volumes 50 + 50 = 100 cm³; mass 500 g; density 5 g/cm³
Stretch: What is the density of an alloy of equal masses 100 g of A (density 5) and 100 g of B (density 20)?
Show answer
Volumes 20 + 5 = 25 cm³; 200 ÷ 25 = 8 g/cm³

5.9Reading speed–time and distance–time graphs

Key learning: On a distance–time graph, gradient = speed and a flat line = stopped. On a speed–time graph, gradient = acceleration and area = distance.

Check: A cyclist rides 12 km in 40 min, rests 20 min, then rides back in 60 min. Find the speed of the first part and the return, in km/h.
Show answer
First part 12 ÷ (2/3) = 18 km/h. Return 12 ÷ 1 = 12 km/h.
Stretch: Find the cyclist’s average speed for the whole journey.
Show answer
24 km in 2 hours = 12 km/h
Unit 6Probability9 subtopics

6.1Sample space diagrams

Key learning: List every outcome in a table or grid, then count favourable outcomes ÷ total outcomes.

Check: Two fair dice are thrown and the scores are added. Find P(total = 7).
Show answer
6 outcomes out of 36 = 1/6
Stretch: Find P(total greater than 9).
Show answer
(4,6),(5,5),(6,4),(5,6),(6,5),(6,6) = 6/36 = 1/6

6.2Probability of an event not happening

Key learning: P(not A) = 1 − P(A). All probabilities add up to 1.

Check: The probability it rains tomorrow is 0.35. Find the probability it does not rain.
Show answer
1 − 0.35 = 0.65
Stretch: P(red) = x, P(blue) = 2x and P(green) = 0.1. Find x.
Show answer
3x + 0.1 = 1, so x = 0.3

6.3Missing probabilities (mutually exclusive)

Key learning: The probabilities of all possible outcomes add to 1, so subtract the known ones from 1.

Check: A spinner lands on 1, 2, 3 or 4 with probabilities 0.2, x, 0.3, 0.15. Find x.
Show answer
1 − (0.2 + 0.3 + 0.15) = 0.35
Stretch: P(A) = 2y, P(B) = y + 0.1, P(C) = 0.2 and no other outcomes. Find y.
Show answer
3y + 0.3 = 1, so y = 7/30

6.4Expected frequency

Key learning: Expected frequency = probability × number of trials.

Check: A fair dice is rolled 300 times. How many sixes are expected?
Show answer
1/6 × 300 = 50
Stretch: A game is won with probability 0.18. Roughly how many wins in 250 plays?
Show answer
0.18 × 250 = 45

6.5Addition rule

Key learning: For mutually exclusive events, P(A or B) = P(A) + P(B).

Check: P(A) = 0.3 and P(B) = 0.45 are mutually exclusive. Find P(A or B).
Show answer
0.3 + 0.45 = 0.75
Stretch: A bag has 5 red, 3 blue and 2 green counters. Find P(red or green).
Show answer
5/10 + 2/10 = 7/10

6.6Frequency from a theoretical probability

Key learning: Multiply the probability by the total number of trials. Rearrange to find the total if the frequency is given.

Check: P(blue) = 3/8. A counter is picked 240 times (replaced each time). How many blues are expected?
Show answer
3/8 × 240 = 90
Stretch: P(blue) = 0.15 and 24 blue counters were counted. How many counters were there in total?
Show answer
24 ÷ 0.15 = 160

6.7Tree diagrams (independent events)

Key learning: Multiply along the branches for “and”, add the end results for “or”. Branches on each set add to 1.

Check: P(rain) = 0.3 on each of two days. Find P(rain on both days) and P(rain on exactly one day).
Show answer
Both: 0.3 × 0.3 = 0.09. Exactly one: 2 × 0.3 × 0.7 = 0.42
Stretch: Find P(rain on at least one day).
Show answer
1 − 0.7 × 0.7 = 0.51 (or 0.09 + 0.42)

6.8Tree diagrams (dependent events)

Key learning: Without replacement the second branches change, because one item has gone. Update numerator and denominator.

Check: A bag has 4 red and 6 blue counters. Two are taken without replacement. Find P(both red) and P(different colours).
Show answer
Both red: 4/10 × 3/9 = 2/15. Different: 2 × (4/10 × 6/9) = 8/15
Stretch: Three counters are taken without replacement. Find P(all blue).
Show answer
6/10 × 5/9 × 4/8 = 1/6

6.9Probability with algebra

Key learning: Write each probability as an expression, multiply for “and”, form an equation, then solve (often a quadratic).

Check: A bag has 3 red and n blue counters. Two are taken without replacement and P(both red) = 1/15. Find n.
Show answer
3/(n+3) × 2/(n+2) = 1/15, so (n+3)(n+2) = 90, n² + 5n − 84 = 0, (n + 12)(n − 7) = 0. n = 7
Stretch: Using your value of n, find P(both blue).
Show answer
7/10 × 6/9 = 7/15
Unit 7Graphs8 subtopics

7.1Pie charts

Key learning: Angle = (frequency ÷ total) × 360°. To read one, find 1° or 1 unit of frequency first.

Check: 12 of 48 students walk to school. What angle is the pie-chart sector?
Show answer
12/48 × 360 = 90°
Stretch: A sector of 72° represents 18 people. How many people in total?
Show answer
72° is 1/5 of the circle, so 18 × 5 = 90

7.2Tables of values: linear and quadratic

Key learning: Substitute each x into the equation carefully. Plot the points and join quadratics with a smooth curve, not ruled lines.

Check: Complete y = x² − 2x − 3 for x = −1, 0, 1, 2, 3.
Show answer
y = 0, −3, −4, −3, 0
Stretch: Write down the turning point and the roots of y = x² − 2x − 3.
Show answer
Turning point (1, −4). Roots x = −1 and x = 3

7.3Cubic, reciprocal and exponential tables

Key learning: Cubic: S-shape. Reciprocal: two separate branches and never touches the axes. Exponential: always positive, rapid growth.

Check: Complete y = x³ − 3x for x = −2, −1, 0, 1, 2.
Show answer
y = −2, 2, 0, −2, 2
Stretch: Complete y = 6/x for x = 1, 2, 3, −2 and y = 2ˣ for x = −1, 0, 3.
Show answer
6, 3, 2, −3. And 0.5, 1, 8

7.4Recognising graph types from equations

Key learning: y = mx + c is a line, x² gives a parabola (U or ∩), x³ an S-shape, 1/x two curved branches, aˣ a curve rising from the x-axis.

Check: Name the graph shape: (a) y = 2x + 1 (b) y = x² − 4 (c) y = x³ (d) y = 3/x (e) y = 2ˣ.
Show answer
(a) straight line (b) U-shaped parabola (c) cubic S-curve (d) reciprocal, two branches (e) exponential curve
Stretch: Describe y = −x³ + 2 and y = −x² + 5.
Show answer
−x³ + 2: S-curve going from top-left to bottom-right. −x² + 5: upside-down parabola with maximum (0, 5)

7.5Trigonometric graphs

Key learning: y = sin x and y = cos x repeat every 360° and lie between −1 and 1. y = tan x repeats every 180° and has asymptotes at 90°, 270°.

Check: State the maximum value, minimum value and period of y = sin x. What is cos 0°?
Show answer
Max 1, min −1, period 360°. cos 0° = 1
Stretch: Solve sin x = 0.5 for 0° ≤ x ≤ 360°.
Show answer
x = 30° and 150°

7.6Non-linear simultaneous equations graphically

Key learning: The solutions are the x and y values where the two graphs cross.

Check: The graphs y = x² and y = x + 2 cross. Find the points of intersection.
Show answer
x² = x + 2, so x² − x − 2 = 0, x = −1 or 2. Points (−1, 1) and (2, 4)
Stretch: Find the intersections of the circle x² + y² = 25 and the line y = x + 1.
Show answer
2x² + 2x − 24 = 0, x = 3 or −4. Points (3, 4) and (−4, −3)

7.7Approximate solutions using a horizontal line

Key learning: To solve f(x) = k using a drawn graph of y = f(x), draw the horizontal line y = k and read the x values where it crosses.

Check: Using the graph of y = x² − 2x − 3, which line do you draw to solve x² − 2x − 3 = 2? Give both solutions to 2 d.p.
Show answer
Draw y = 2. x² − 2x − 5 = 0 gives x = 1 ± √6 = 3.45 or −1.45
Stretch: Which line do you draw to solve x² − 3x − 4 = 0 using the same graph?
Show answer
x² − 2x − 3 = x + 1, so draw y = x + 1. Solutions x = −1 and 4

7.8Turning points by completing the square

Key learning: For y = (x + p)² + q the minimum point is (−p, q). For y = q − (x + p)² it is a maximum.

Check: Write y = x² − 6x + 5 in the form (x + p)² + q and state the minimum point.
Show answer
(x − 3)² − 4. Minimum (3, −4)
Stretch: Find the maximum point of y = −x² + 4x + 1.
Show answer
−(x − 2)² + 5. Maximum (2, 5)
Unit 8Sine and Cosine Rule9 subtopics

8.1Sine rule: finding a side

Key learning: a/sin A = b/sin B. Use it when you have a matching side-angle pair and one more angle.

Check: In triangle ABC, A = 40°, B = 65° and a = 8 cm. Find b (3 s.f.).
Show answer
b = 8 sin 65° ÷ sin 40° = 11.3 cm
Stretch: In triangle ABC, A = 35°, C = 80° and c = 12 cm. Find a (3 s.f.).
Show answer
a = 12 sin 35° ÷ sin 80° = 6.99 cm
