Q22(c) worked through — and a genuine subtlety

Question: the equation x³+x²−x = k has fewer than 3 solutions. Find the range of possible values of k.
The idea — vertical translation: solving x³+x²−x = k is the same as asking how many times the horizontal line y = k crosses the curve y = x³+x²−x. Equivalently, this is the same as taking the fixed curve y = x³+x²−x−k (the original curve translated vertically by −k) and asking how many times it crosses the x-axis. As k changes, the whole curve effectively slides up or down past a fixed horizontal line, and the number of crossings changes only when the line passes through one of the two stationary points.
From part (a): the two stationary points are (−1, 1) — a local maximum — and (1/3, −5/27) — a local minimum.
Reading the sketch: while k is strictly between −5/27 and 1, the line y = k passes through the "hump" of the curve and crosses it 3 times. Once k moves above 1 or below −5/27, the line only crosses once. So the standard, expected answer is k > 1 or k < −5/27.
The subtlety worth discussing with her: the question you raised is a good one. At exactly k = 1 or k = −5/27, the line touches the curve at the stationary point rather than crossing it, which produces a repeated root there. Checking algebraically: at k = 1, x³+x²−x−1 factorises as (x+1)²(x−1) — a repeated root at x = −1 and a single root at x = 1, giving 2 distinct solutions, not 3. The same happens at k = −5/27. So strictly speaking, "fewer than 3 solutions" is also true at the boundary itself, and a fully rigorous answer would be k ≥ 1 or k ≤ −5/27.
Why the mark scheme still asks for the strict version: Cambridge's official mark scheme awards full marks for the strict inequalities (k > 1 or k < −5/27) as the expected answer, and separately allows a special-case mark for the inclusive version. In practice this is a case where the exam's expected answer and the fully rigorous answer differ slightly at the boundary — a nice discussion point, but for exam purposes the strict version is the one to write down.

Q23(b) worked through in base 2

Question: 16x × (1/2)x = 4x+3. Find the value of x.
Step 1 — rewrite every term with base 2: 16 = 24, so 16x = (24)x = 24x. Also 1/2 = 2−1, so (1/2)x = (2−1)x = 2−x. And 4 = 22, so 4x+3 = (22)x+3 = 22(x+3) = 22x+6.
Step 2 — substitute back into the equation: 24x × 2−x = 22x+6.
Step 3 — combine the left-hand side using the rule for multiplying powers with the same base (add the exponents): 24x + (−x) = 23x. So the equation becomes 23x = 22x+6.
Step 4 — equate the exponents (same base on both sides, so the powers must be equal): 3x = 2x + 6.
Step 5 — solve: 3x − 2x = 6, so x = 6.
Where the working differed: the recorded working converted the right-hand side to 22(x+3) correctly, but combined 16x and (1/2)x directly into 82x without going through the base-2 form of each term individually. Converting every term to base 2 first, one at a time as above, keeps each exponent rule separate and avoids that slip.

Three answers (Q5, Q7, Q8a) were mathematically correct but hard to mark at first glance, and two of them (Q7, Q8a) trace back to the same cause: a 4 written with a closed top that reads as a 9. Combining indices before converting

In Q23(b), 16x × (1/2)x was converted to 82x instead of 8x. Converting every term to the same base individually first (as in the guideline above), rather than combining bases part-way through, would remove this source of error.
