Question 19 — Indices equation

Q19Solving (1/3)x = 9x+4Left blank−3 marks

This was left blank, so here's the full route through it:

Step 1: rewrite 1/3 as 3−1, so the left side becomes 3−x.
Step 2: rewrite 9 as 32, so the right side becomes 32(x+4).
Step 3: both sides now have the same base (3), so the powers must be equal: −x = 2(x+4).
Step 4: −x = 2x+8 → −3x = 8 → x = −8/3.

Question 24 — Vectors

Q24Position vector of MMisconception−3 marks

You earned 1 mark for the correct route: OM = OB + BC + CM.

The mistake: BD isn't ⅓ of b. OB is b — but in your redrawn diagram, b ended up being used for OD instead, which threw off everything that followed.

Here's how to find BD properly:

BD = ⅓ of OD, and OD = OB + BD = b + BD
So BD = ⅓(b + BD)
3BD = b + BD → 2BD = b
BD = ½b

Now find CD (using BC = ⅓a, so CB = −⅓a):

CD = CB + BD = −⅓a + ½b

M is the midpoint of CD, so:

CM = ½CD = ½(−⅓a + ½b) = −1/6 a + ¼b

Finally, put it all together:

OM = OB + BC + CM = b + ⅓a + (−1/6 a + ¼b)
OM = 1/6 a + 5/4 b
